# Security, Secrets, and Rights Handling

## Secrets

Never commit passwords, browser cookies, personal sessions, company account credentials, API keys, GitHub tokens, Bloomberg credentials, data-license files, or private connector configuration. Store runtime values in the execution environment’s secret manager or local untracked `.env` file. Keep `.env.example` names only.

## Licensed and subscription content

Use source content only under the company’s actual entitlement. Keep the source name, URL, access type, timestamp, and permitted factual synthesis in the internal source log. Do not evade publisher restrictions, bypass a paywall, scrape protected material outside permission, or claim that an inaccessible article body was read.

## Brand assets

Use the official files already in `client/public/brand/` only for this repository’s approved BIT market-intelligence purpose. Do not export, repurpose, or alter official logos and fonts beyond their license and brand rules. See `BRAND_MATERIAL_HANDOFF.md`.
